# Sicherheitsrichtlinie

## Unterstützte Version

Sicherheitskorrekturen gibt es jeweils für die **aktuelle veröffentlichte Version**. Bitte aktualisiere zuerst, bevor du ein Problem meldest.

## Eine Sicherheitslücke melden

Bitte melde Sicherheitslücken **nicht** als öffentliches Issue.

Nutze stattdessen auf GitHub den Reiter **Security** → **Report a vulnerability**. Die Meldung bleibt privat, bis eine Korrektur veröffentlicht ist.

Hilfreich sind:
- eine kurze Beschreibung des Problems und was damit möglich ist
- die Schritte, um es nachzuvollziehen
- die betroffene Version

## Was dich erwartet

Ich antworte in der Regel innerhalb weniger Tage, melde mich zum Stand der Korrektur und nenne dich auf Wunsch in den Versionshinweisen.

Die App ist ein privates Hobbyprojekt. Bitte habe Verständnis, dass es keine feste Reaktionszeit und keine Prämien gibt.
