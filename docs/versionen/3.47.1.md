# 3.47.1

**Fehlerkorrektur: Die Notizbox der Tour war bei vielen Touren höher als nötig.**

- Ursache: Die Größen-Merkfunktion (`rememberSize`) speicherte auch die automatisch vergrößerte Höhe, wenn eine lange Notiz die Box wachsen ließ. Jede andere Tour startete danach mit dieser Höhe als Mindesthöhe.
- Jetzt wird nur noch eine vom Nutzer gezogene Höhe (oder Breite) gemerkt. Der Speicherschlüssel heißt `size2:…`, damit bereits verfälschte Werte einmalig verfallen; eine selbst gewählte Größe muss einmal neu gezogen werden.
- Test: `tests/test_browser.py::test_stars_safety_compare_and_note_size` prüft, dass die automatische Höhe nicht gemerkt wird.
