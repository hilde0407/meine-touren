## Nebenseiten unter der Schutzrichtlinie

Die Freigabe-Seite (`/s/…`), die Diashow und die Seite zum Zurücksetzen des Passworts enthalten
kein Inline-JavaScript mehr – ihr Code liegt jetzt in eigenen Dateien. Dadurch gilt die
Content-Security-Policy, die bisher nur für die Hauptoberfläche galt, auch für diese Seiten:
Skripte dürfen nur noch vom eigenen Server kommen, eingeschleuster Code läuft nicht.

## Gezeichnete Symbole statt Emojis

Emojis am Anfang von Knöpfen, Chips und Links werden app-weit durch Liniensymbole in
Schriftfarbe ersetzt. Die Oberfläche sieht damit auf jedem Betriebssystem gleich aus,
statt je nach Gerät unterschiedlich bunt.

## Lesbarkeit im Dunkelmodus

„Löschen …“ war auf dunklem Grund kaum zu lesen (Kontrast 2,4:1). Jetzt gibt es je Modus
einen eigenen Farbton: 7,9:1 im Dunkelmodus, 6,5:1 im Hellmodus.

## Aufbau aufgeräumt (nichts sichtbar, aber wartbarer)

Vier Bereiche sind aus den gewachsenen Sammelstellen in eigene Module gewandert:
Selbsttest, Wanderführer, „gleiche Strecke mehrfach“ und Gipfelnamen.
`extras.py` schrumpft von 843 auf 611 Zeilen, `more.py` von 599 auf 424.
