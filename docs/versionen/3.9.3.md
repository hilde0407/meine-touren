# 3.9.3

- **Ältere Amazfit-Uhren werden besser erkannt:** Uhren aus der Zeit vor Zepp OS melden statt einer Nummer einen Codenamen (z. B. `run.watch.everest.huami.com`). „Geräte aus Zepp ermitteln“ schlägt dafür jetzt ein Modell vor (everest → Amazfit Stratos, qogir → Amazfit Verge, nur `watch` → Amazfit Pace). Diese Vorschläge sind **Vermutungen** und im Dialog entsprechend gekennzeichnet – bitte prüfen und bei Bedarf ändern. Kennungen mit Nummer aus der Zepp-Geräteliste (z. B. GTR 2, GTR 3 Pro, GTR 4) bleiben sicher erkannt.
